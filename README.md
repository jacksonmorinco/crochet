# Blanket Planner

A static web app for designing a crochet blanket on a grid whose cells match a real stitch's proportions. It's set up for Lion Brand Wool-Ease Thick & Quick on a 10 mm (N/15) hook.

- Label gauge is 6 sc × 8 rows = 4″ on a 9 mm hook. The app scales that for your hook size, or you can enter a measured swatch.
- Stitch types: sc, moss, hdc, dc. Taller stitches get taller cells.
- Tools: brush, fill, rectangle, line, color picker, stitch marks, mirror symmetry, and undo/redo.
- Shows yards and skeins per color, the stitches for each row in working order, and a crafting mode for following the pattern.
- Autosaves in the browser. Save a design as a file (to open later) or as a PNG with a color legend.

No build step. Open `index.html` or serve the folder.

Hosted on GitHub Pages at https://crochet.jmco.app (see `CNAME`).
